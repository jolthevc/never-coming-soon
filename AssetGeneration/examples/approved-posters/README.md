## Visual calibration

The aesthetic is tactile, intentionally composed, and often vintage-print-inspired: textured paper, graphic or painted objects, editorial typography, an ivory paper border when appropriate, restrained branding, and a strong single story-specific idea. The approved images favor concept and design over photorealistic scene illustration.

Do not force every film to use the same palette or poster layout. The fictional production owns its poster; NCS owns the deterministic editorial Slides 1 and 2.

Do not reproduce another film's symbolic objects. Do not let example typography replace exact `ig_packet_json` copy. Avoid overly glossy photographic realism, generic movie key art, and arbitrary prop piles.

For reference-guided API generation, pass the actual image bytes, not just a filepath in text. These examples are only calibration assets, not universal image-conditioning inputs.

## Asset status

The seven approved PNGs in this folder are the reference library. For each production, select two contrastive examples and provide direct links to the actual PNGs. These are style and professional-quality calibration references, not objects, narratives, or layouts to copy. Verify actual binary availability before promising the images can be inspected.
