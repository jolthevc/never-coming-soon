# Shared Leash: visual calibration

These are three **individual 1080 × 1440** examples, collected from iterations of the project. They show the direction, not a production-ready packet for future films. Read the scope of each approval carefully.

| File | What it demonstrates | Limit |
| --- | --- | --- |
| [01-hook.png](01-hook.png) | The preferred text-first hierarchy: category first, title second, readable one-line idea third; cream/navy/red and ample air. | This image precedes the optional footer convention. Do not force an inconsistent footer onto it just to match the plot sample. |
| [02-plot.png](02-plot.png) | The accepted clean editorial direction: kicker, red accent, THE PLOT, two paragraphs, large readable body, one cream background. | This sample uses a **92-word legacy Shared Leash premise**, not a current `ig_packet_json` three-slide plot. It is not proof that a 170-word packet fits at the same font size. The bottom NCS/page footer is exploratory; standardize its position only if used. |
| [03-poster.png](03-poster.png) | A singular object-led poster that makes the movie's relationship and dilemma visible without faces; polished title, rating/format area, restrained billing. | This was created for an earlier carousel stage. Reuse its visual reasoning, not its literal palette, leash, invented billing language, or all of its small-print copy. Future packet text governs exact poster wording. |

The approved direction is **house editorial clarity on Slides 1 and 2, movie-specific iconic payoff on Slide 3**. These images are not a mandate to make all films look like Shared Leash.
